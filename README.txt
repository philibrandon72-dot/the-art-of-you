THE UNLOCK — QUICK START

1. Extract the-unlock-game.zip.
2. Open index.html in Chrome, Edge, Firefox or Safari to test it.
3. To personalise the final message, open index.html in Notepad or VS Code.
4. Find PERSONALISE THESE TWO LINES near the bottom of the file.
5. Replace the text inside PERSONAL_MESSAGE and SIGN_OFF. Keep the quotation marks.
6. Save and test again.

LOCAL TESTING WITH XAMPP
- Copy the whole 'the-unlock-game' folder into C:\xampp\htdocs\
- Visit http://localhost/the-unlock-game/

SHARING
To let her open it on her own phone, upload the folder to a static HTTPS hosting service (for example, GitHub Pages or Netlify) and send her the public URL. Opening localhost only works on your own computer.
The game has no accounts, database, tracking or external backend. Google Fonts are optional; if offline, it falls back to system fonts.
